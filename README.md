# 🎹 Fruit Bot (蝠乐达) - 免费音乐制作软件

**Fruit Bot** 是一款完全免费、轻量级的数字音频工作站（DAW）。

它或许比不上那些动辄数千元、甚至上万元的商业级宿主软件，但对于一些无力承担高昂软件费用的独立音乐人、学生或游戏开发者来说，它将是一款用于助力你制作音乐的实用工具。

## 💡 为什么会有这个项目？

做它的原因很朴素：我是一名 15 岁的学生，自己承担不起主流商业 DAW 的费用。在尝试寻找开源替代品时，我发现很多免费工具的门槛依然很高，或者过于臃肿。

所以我花了几天时间，自己写了这个软件。它不仅是为了帮助我自己，也希望能帮到更多被“付费墙”拦住音乐梦想的人。

## ✨ 当前版本包含的功能

*   **基础编曲与多轨混音**：支持自由增减音轨。
*   **内置合成器与音色**：包含基础的振荡器、包络和预设乐器，能捏出简单的音色。
*   **音频剪辑与处理**：支持导入音频，基础的时间拉伸与变调功能。
*   **录音功能**：支持倒计时录音（最新版）。
*   **乐谱导出**：支持导出标准 MusicXML 格式及图片谱。
*   **极简轻量**：安装包压缩后仅约 16.5MB。
*   **多语言**：内置八国语言翻译。

*(注：软件仍在不断完善中，部分底层算法还有较大的优化空间，欢迎指正。)*

# 🎹 Fruit Bot - A Free DAW for Music Production

**Fruit Bot** is a completely free and lightweight Digital Audio Workstation (DAW). 

It may not rival expensive, commercial-grade software, but for independent musicians, students, or game developers who cannot afford premium DAWs, it is designed to be a practical tool to help you produce your own music.

## 💡 Why does this project exist?

The reason is simple: I am a 15-year-old student and cannot afford the subscription or license fees for mainstream commercial DAWs. When looking for open-source alternatives, I found that many free tools were either too complex to set up or too bloated for my needs.

So, I spent a few days building this. It's not just for myself, but for anyone else whose musical dreams are blocked by paywalls.

## ✨ Current Features

*   **Basic Sequencing & Multi-track Mixing**: Supports dynamic track creation.
*   **Built-in Synth & Instruments**: Includes basic oscillators, envelopes, and preset instruments for sound design.
*   **Audio Editing**: Supports audio import, basic time-stretching, and pitch-shifting.
*   **Recording**: Supports count-in recording (in the latest version).
*   **Score Export**: Supports standard MusicXML export and image scores.
*   **Lightweight**: The compressed installation package is only about 16.5MB.
*   **Multi-language**: Includes 8 different languages.

*(Note: The software is still under active development. Some underlying algorithms have room for optimization. Feedback is always welcome.)*

## 📦 How to Get It

*   **Free Open-Source Version**: You can download the open-source build from the `Releases` page, or pull the source code and compile it yourself. Core features are 100% free.
*   **Latest Sponsor Version**: If you'd like to support a 15-year-old indie developer, you can buy me a coffee (or treat my parents to a hotpot). Sponsors get the latest stable pre-compiled executable and detailed tutorials.
*   **Open Source Promise**: I am committed to the open-source spirit. With every new release, the previous version (including all core code) will be immediately merged into this repository for everyone to use for free.

## 🤝 Looking for Fellow Creators: Open-Source Audio Samples

Due to budget constraints, the built-in instrument samples currently rely on open-source libraries. The quality of some sustained samples (like the loop points for strings) still has flaws. I've tried many algorithms to fix this, but the results are limited.

If there are any musicians or audio engineers here:
If you are willing to provide clean, dry instrument recordings (e.g., violin or flute sustained notes, 48kHz/24bit), I would be extremely grateful. Your name will be permanently credited in the software's "About" section.
